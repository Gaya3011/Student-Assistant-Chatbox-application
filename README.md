# Student-Assistant-Chatbox-application

🎓 Student Assistant Chatbot

A lightweight, full-stack web application designed for college projects and viva demonstrations. Built with HTML, CSS, JavaScript, Python, and Flask, this chatbot provides instant, automated answers to common student inquiries regarding college schedules, courses, attendance rules, library policies, and departmental contact information—all without requiring full page refreshes

📁 Project Structure

student-assistant-chatbot/
│
├── app.py              # Flask backend server & chatbot matching logic
├── templates/
│   └── index.html      # Web interface layout & JavaScript AJAX fetch code
└── static/
    └── style.css       # Chat UI layout, bubbles, and visual styling
